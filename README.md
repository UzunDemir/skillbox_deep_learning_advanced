# Skillbox Deep Learning Advanced 📘

Welcome to the **Skillbox Deep Learning Advanced** repository — a curated collection of practical exercises and notebooks from the *Advanced Deep Learning* course at **Skillbox**.

This project captures hands‑on deep learning practice as I worked through real assignments, built neural network models, explored core concepts, and strengthened my skills with real code examples.

## 🎯 What’s Inside

This repository includes a set of Jupyter notebooks covering:

- 💡 Deep learning exercises and projects  
- 🧠 Neural network implementation experiments  
- 📝 Practical work from advanced course modules  
- 📊 Examples that reinforce theory with practice

Everything here reflects active learning and exploration of deep learning principles through coding and experimentation.

## 📂 Structure

Each notebook represents a practical task or assignment from the course, designed to:

- Build intuition with real data and models
- Practice defining and training neural networks
- Explore results and visualize performance

You can open and run these notebooks using **Jupyter Notebook** or **VS Code** with Python support.
